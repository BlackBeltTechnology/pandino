features:
  - title: Service Registry
    details: Services discover each other dynamically through a central registry with LDAP-filtered selection and automatic ranking.
  - title: Bundle System
    details: Self-contained modules with independent lifecycles. Start in any order — dependencies resolve automatically.
  - title: Declarative Services
    details: Decorator-based dependency injection eliminates boilerplate service wiring with @Component, @Service, and @Reference.
  - title: React Integration
    details: Hook-based service discovery for React components with useService, useServiceTracker, and PandinoProvider.
  - title: Event System
    details: Publish-subscribe messaging with topic-based routing via EventAdmin. Decouple modules with sync and async events.
  - title: Configuration Management
    details: Runtime configuration updates without restarts via ConfigurationAdmin. Services react to config changes automatically.
